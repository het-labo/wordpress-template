# Hopmarkt Starter Theme

This child theme streamlines building brochure and property marketing sites on top of Twenty Sixteen. It exposes the homepage layout, company metadata, and several utility toggles via the WordPress Customizer so new projects can reuse the layout without editing templates.

## Highlights

- Configurable hero, feature, practical, and news sections for the front page.
- Dedicated footer menu locations and contact fields driven by Customizer settings.
- Optional Tailwind playground script and robots `noindex` toggle for staging environments.
- Sensible defaults for accessibility styles and navigation scripts.

## Getting started

1. Install and activate the Twenty Sixteen parent theme.
2. Copy this child theme into `wp-content/themes` and activate it.
3. Visit **Appearance → Customize** to set company information and tailor the homepage content.
4. Assign menus to the `Footer primary links`, `Footer secondary links`, and `Footer utility links` locations for complete footer navigation.

Feel free to extend the placeholder `inc/custom-fields.php` module with project-specific field registrations when integrating with Advanced Custom Fields or similar plugins.
